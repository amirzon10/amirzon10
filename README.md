### 🚀 Projects

**⚖️ [Bias in RAG Across Small LLMs](https://github.com/amirzon10/Does-RAG-Reduce-Bias-)**
My award-winning final-year project (NCI 75th Anniversary Award for Best Project) investigating whether Retrieval-Augmented Generation reduces bias across multiple open-source small LLMs, examining bias across several categories.

**🌍 [Urban CO₂ Streaming](https://github.com/amirzon10/urban-co2-streaming)**
Event-driven microservices architecture for real-time urban CO₂ monitoring and traffic density correlation, using Kafka, Faust, InfluxDB, and Grafana.

**💊 [IoT Pharma Monitor (AWS)](https://github.com/amirzon10/iot-pharma-monitor-aws)**
Cloud-native IoT monitoring system for pharmaceutical cold-chain logistics, built with AWS, Node-RED, and Chart.js.

**📰 [AI Regulation Discourse in News (2020–2025)](https://github.com/amirzon10/AI-Regulation-Discourse-in-News-A-Longitudinal-Study-Post-ChatGPT-2020-2025-)**
Longitudinal analysis of AI regulation discourse in global news media pre- and post-ChatGPT, using sentiment analysis, NER, and multilingual NLP.

**🖼️ [Image Classifier (ResNet50 & VGG16)](https://github.com/amirzon10/Image-Classifier-using-ResNet50-and-VGG16-Evaluation-and-Testing)**
